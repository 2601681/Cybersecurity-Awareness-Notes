# Cybersecurity-Awareness-Notes
Phishing awareness: Phishing is a common cybercrime in which an attacker sends messages or emails to people in order to gain sensitive ion like ID number, passwords. This awareness mainly deals with the educational part of which people get training on how they could safeguard their devices, the security tips they should use to protect their personal information.
These are the security measures that one can use to enhance security: One should not click a suspicious link to prevent cases of phishing.
Use the Multifactor Authentication so that an outsider or attacker is unable to access one's information easily.
Make sure to update software or applications .
